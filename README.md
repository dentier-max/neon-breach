# NEON BREACH / 霓虹突袭

支持手机、平板与桌面浏览器的单文件第一人称科幻枪战游戏。

## 在线游玩

**https://dentier-max.github.io/neon-breach/**

建议使用横屏并点击「进入战区」开启全屏。

## 特性

- 触屏优化：左摇杆移动、右侧拖动瞄准、FIRE 持续射击、瞄准 / 换弹 / 切枪 / 跳跃
- 桌面端：WASD + 鼠标指针锁定 + 键盘操作
- 5 波围攻，包含机兵、精英、无人机与最终 Boss「监督者」
- 2 把武器、瞄准 / 换弹 / 切枪、爆头、连击评分、补给与战术小地图
- 所有场景、角色、武器、音效均由代码实时生成，无外部依赖
- 手机 / 平板自动降分辨率并提供触屏 HUD，桌面端保持完整画质

## 触屏操作

| 控制 | 功能 |
| --- | --- |
| 左下摇杆 | 移动（推到边缘自动冲刺） |
| 屏幕右侧拖动 | 瞄准 |
| FIRE | 持续射击 |
| 瞄准 | 切换瞄准状态 |
| R | 换弹 |
| ⇄ | 切换武器 |
| ↑ | 跳跃 |
| 顶部 Ⅱ | 暂停 |

## 桌面操作

`WASD` 移动 · `鼠标` 瞄准 · `左键` 射击 · `右键` 瞄准 · `R` 换弹 · `Shift` 冲刺 · `Space` 跳跃 · `Ctrl` 蹲伏 · `1/2` 切枪 · `F` 全屏 · `Esc` 暂停

## 本地运行

直接双击 `index.html`，或启动任意静态服务器后打开。无需构建步骤。
